# 🚀 Factory-OEM Shopify Store Spy & Theme Detector

A lightweight, zero-install open-source web tool designed for eCommerce entrepreneurs, dropshippers, and brands to instantly reverse-engineer any competitor's Shopify store. 

Find out exactly what **Shopify Theme** they are running and what **Conversion-boosting Apps** they have installed under the hood with just one click.

👉 **[Live Demo & Free To Use Here](https://github.io)**

---

## 💡 Key Features
- **Instant Theme Detection:** Identifies whether a store uses standard Shopify themes (like Dawn) or premium customized templates.
- **App Stack Footprint Scanner:** Detects industry-standard apps for email marketing, product reviews, page builders, and subscriptions (e.g., Klaviyo, Loox, Judge.me, PageFly, Gorgias, and more).
- **100% Free & Serverless:** Runs entirely in the browser using public proxy APIs—no server tracking, no installation, and absolute privacy.

## 🛠️ How to Deploy Your Own
Since this project is open-source and built with vanilla HTML/CSS/JavaScript, you can host your own copy in under 60 seconds:

1. **Fork** this repository.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment**, set the branch to `main` (or `master`) and click **Save**.
4. Your clone is now live!
